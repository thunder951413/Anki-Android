# 小海豹学习：使用场景与体验评估

范围：`com.ichi2.anki.learning` 包（`LearningActivity`、`LearningRepository`、`SshSettingsActivity`、`SshTunnelService`、`SyncEndpointSwap`），以及 `assets/learning` 里的 Web 课程界面。
基线：`codex/seal-learning` 分支上用户提交的版本（commit `de32bab` 与 `a9c6812`）。

严重度：**P0** 会丢数据或改坏用户设置；**P1** 主要路径受阻或明显变慢；**P2** 体验问题；**P3** 打磨项。

---

## 1. 典型用户

| 人物 | 情境 | 关注点 |
| --- | --- | --- |
| 小林，初二 | 在手机上复习从 StudyMate 导入的「小海豹通用学习」卡片，每次 5–10 分钟 | 入口好找、题目好答、错了知道为什么、随时能停 |
| 小林的家长 | 配置自建同步服务器，经由 SSH 隧道同步，自己不常用 Anki | 步骤清楚、不怕点错、不会把孩子原来的 AnkiWeb 登录弄丢 |
| 通勤中的学生 | 地铁里断断续续学习：来电、切应用、锁屏、横屏 | 中断后进度不丢、复习记录不重复 |
| 离线用户 | 没有网络或隧道没连上 | 课程照常可用；同步失败不影响学习 |
| 大牌组用户 | 几千张卡、十几个科目子牌组 | 课程列表秒开、能找到想学的科目 |

## 2. 路径走查与发现

### 2.1 入口

- 入口在牌组列表右上角溢出菜单「小海豹学习」（`showAsAction="never"`）。孩子第一次很难发现。**P2**，未改动：要改得醒目需要修改上游的 DeckPicker 布局，留作后续建议（见第 5 节）。
- 菜单标题原本硬编码为中文默认值，英文系统也显示中文。**P3，已修复**：默认 `values/` 为英文，`values-zh/` 为中文。

### 2.2 课程列表（home）

| # | 问题 | 严重度 | 处理 |
| --- | --- | --- | --- |

| H2 | 启动时依次重试本地待保存记录，**任何一条失败（包括 STALE）都会抛出，整个课程列表加载失败** | P0 | **已修复**：`flushPending()` 逐条重试、吞掉失败；STALE 的直接丢弃，其余保留到下次 |
| H3 | 列表只显示「N 个练习目标」，看不出今天哪个科目该学 | P2 | **已修复**：按「今天要复习 / 其他课程」分组，显示「N 题到期 · M 道新题」或「今天已完成」，到期多的排前面 |
| H4 | 未开启 FSRS 时仍可点课程，点进去才报错 | P2 | **已修复**：顶部醒目提示 + 「打开复习设置」，课程按钮禁用 |

| H8 | 卡片笔记类型因导入冲突被 Anki 改名为「小海豹通用学习-xxxxx」后，课程直接消失 | P1 | **已修复**：同时识别带 `-后缀` 的副本 |

### 2.3 开始一课

| # | 问题 | 严重度 | 处理 |

| L2 | 一次最多处理 1000 张排队卡，逐张 `note()`，对缺记忆状态的卡还做 `computeMemoryState` | P1 | **已修复**：候选数以牌组每日上限（`deckDueTree` 的 review/learn/new 计数）为界，且最多 60 张到期 + 12 张新卡；`computeMemoryState` 只对这些候选里缺状态的卡做 |
| L3 | 一张卡的练习 JSON 坏了，`JSONObject()` 抛错，整个课程打不开 | P1 | **已修复**：坏卡跳过并计数（Kotlin 与 JS 两侧都做），小海豹提示「有 N 张卡格式有误，已跳过」 |
| L4 | 连点课程卡会并发发起多次 `lesson` 请求 | P2 | **已修复**：`busy` 防抖，并显示加载状态 |
| L5 | 没有到期题时提示写在小海豹气泡里，但页面没变，容易以为没点上 | P3 | **已修复**：回到列表并用提示气泡说明 |

### 2.4 答题

| # | 问题 | 严重度 | 处理 |
| --- | --- | --- | --- |

| Q2 | 选择题答错后不标出正确选项 | P2 | **已修复**：正确项标绿、选错项标橙；非选择题显示「正确答案：…」 |
| Q3 | 「巩固 · 权重 35」对学生是内部术语 | P2 | **已修复**：只显示「到期复习 / 重点复习 / 新题」等标签 |
| Q4 | 双击「继续」会第二次调用 `session.next()`，抛出「先提交当前步骤再继续」未捕获异常 | P1 | **已修复**：按钮点击后立即禁用 |
| Q5 | 输入题回车即检查，但检查后再按回车不会继续；中文输入法组字时回车会误触发 | P2 | **已修复**：统一键盘处理，回车 = 检查 / 继续，忽略 `isComposing` |
| Q6 | 排序题看不出顺序，选中的块与待选块样式一样 | P2 | **已修复**：已排部分显示序号，虚线框区分 |
| Q7 | 图片定位题的「横向/纵向百分比」输入框对孩子很突兀 | P3 | **已修复**：收进「无法点按？用数字输入位置」折叠区，保留给无障碍用户 |
| Q8 | 音频/图片缺失时显示破图或无响应 | P2 | **已修复**：加载失败时显示文字说明 |
| Q9 | 语音：设备没有语音识别服务时抛 `ActivityNotFoundException`，提示是英文技术信息；等待识别期间 45 秒超时会误报 | P2 | **已修复**：给出「这台设备没有语音识别服务，请直接输入答案」；语音请求不设超时；识别中按钮禁用 |
| Q10 | 数值题键盘只出数字，无法输入单位 | P3 | 保持普通键盘（单位需要字母） |

### 2.5 评分与写回

- 评分逻辑保持不变：答错过 → Again(1)，用过提示 → Hard(2)，否则 Good(3)。token 写入 `customData.lp.t` 保证重试幂等，`expectedReps`、`contentHash` 防止覆盖别处的复习。这部分设计是对的，已有测试覆盖。
- **R1（P1，已修复）**：保存失败时「继续」按钮一直禁用，只能反复点「重试保存」；数据库忙时孩子会卡住。现在提供「重试保存」和「先继续，稍后自动保存」；记录留在本地发件箱，下次保存或回到列表时自动重试。
- **R2（P2，已修复）**：STALE 时只给「刷新课程」，本节课被迫中断。现在说明原因后允许继续。
- **R3（P2，已修复）**：Kotlin 错误信息硬编码中文，并靠字符串前缀 `STALE:` 判断。现在用 `LearningException(messageRes, stale)`，文案在 strings 资源里，由 Activity 翻译成当前语言。
- 三次答错后放弃该步时，原实现即使第三次答对也算 `exhausted`。**已修正**：只有答错才算。

### 2.6 中途退出再继续

| # | 问题 | 严重度 | 处理 |
| --- | --- | --- | --- |
| E1 | 课程状态只在内存里。旋转屏幕、切深色模式、进程被杀（来电后很常见）都会让 Activity 重建，**整节课丢失** | P0 | **已修复**：`LessonSession.snapshot()/restore()`，每次出题和提交后存到 localStorage；首页显示「继续上次的短课 · 已完成 x / y」。Manifest 增加 `configChanges`，旋转、键盘、窗口大小变化不再重建 WebView |
| E2 | 返回键直接关闭 Activity，答题中误触就退出 | P1 | **已修复**：返回键交给页面：有对话框先关对话框；答题中弹出「退出这节短课？」；总结页回到列表；列表页才真正关闭 |
| E3 | 退出确认用 `window.confirm()`，样式是系统 WebView 对话框，文案只有一句 | P3 | **已修复**：页面内对话框，默认焦点在「继续学习」 |

### 2.7 完成后的总结与衔接

- **F1（P2，已修复）**：总结只有三个数字。现在有完成数、练习次数、正确率、用时，并列出「这些题会更快再见面」（答错或用过提示的题）和可展开的「已经掌握」。
- **F2（P2，已修复）**：只能「返回课程」。现在可「再学一节」（同一课程剩余到期题）、「返回课程」或「回到 Anki 复习其他卡片」（关闭页面回到牌组列表，列表会刷新计数）。
- **F3（P2，未改）**：在 Anki 正常复习界面里，这些卡的模板字段是练习 JSON（可能还是 `b64:` 编码），孩子如果在普通复习里刷到会看到一堆代码。这属于卡片模板设计，需要在 StudyMate 端给模板加可读的问答，或把这些卡放进单独的牌组并在普通复习里排除。

### 2.8 SSH 同步（家长配置）

| # | 问题 | 严重度 | 处理 |
| --- | --- | --- | --- |
| S1 | **连接时覆盖用户原有的自定义同步地址并清空 hkey；断开后不恢复**。孩子原来登录的 AnkiWeb 或别的服务器设置直接丢失 | P0 | **已修复**：`SyncEndpointSwap` 连接时备份原设置（地址、开关、hkey、用户名、currentSyncUri），断开时恢复；隧道里的登录按「用户@主机:端口>远端端口」单独记住，下次连接不用重新登录 |
| S2 | 进程被杀后 Service 没了，但同步地址还指向 `127.0.0.1:18765`，之后的同步全部失败 | P1 | **已修复**：打开学习页或 SSH 设置页时，如果 Service 不在运行而备份仍处于激活状态，自动恢复 |
| S3 | 本地端口写死 18765，被占用时直接失败 | P1 | **已修复**：先用上次成功的端口（默认 18765），被占用时让系统分配并记住；登录按 profile 记忆，端口变化不需要重新登录 |
| S4 | **SSH 密码通过 Intent extra 传给 Service**（可能出现在系统日志、`dumpsys`、重投递的 Intent 里） | P0 | **已修复**：`SecretHandoff` 在进程内存中交接，Service 取走后立刻清空引用；Service 停止时把字节数组清零 |
| S5 | 网络切换后 JSch 会话断开，通知栏仍显示「已连接」 | P1 | **已修复**：每 15 秒检查会话，断开后按 2s/10s/30s 重连三次，失败则停止并恢复原设置 |
| S6 | 仅启用 `password` 和未实现 `keyboard-interactive`，很多只开 PAM 的服务器连不上 | P2 | **已修复**：实现只回答隐藏提示的 `UIKeyboardInteractive` |
| S7 | 设置页用 px 内边距、没有处理系统栏 insets（Android 15 默认 edge-to-edge 时内容被状态栏遮住）、状态只是一行字 | P2 | **已修复**：dp 布局、insets、Material 按钮；显示 known_hosts / 私钥的导入状态；连接中禁用「连接」；状态有颜色和无障碍实时播报 |
| S8 | 家长不知道 known_hosts 从哪来 | P2 | **已修复**：页面内写明 `ssh-keyscan` 步骤和「与管理员核对指纹」 |
| S9 | 导入 known_hosts 不做校验，选错文件（例如私钥）也会被当成服务器身份 | P2 | **已修复**：拒绝含 `PRIVATE KEY` 的文件，要求至少一行合法主机密钥 |
| S10 | 删除私钥无确认 | P3 | **已修复**：确认对话框 |
| S11 | Android 13+ 没申请通知权限，前台服务通知看不到，也就找不到「断开」 | P2 | **已修复**：连接时申请 `POST_NOTIFICATIONS`（不阻塞连接） |
| S12 | 通知 ID 与端口号共用 18765 | P3 | **已修复**：独立常量 |
| S13 | 已连接时再次 `startForegroundService` 直接返回、没有调用 `startForeground`，在部分系统上会触发 ANR/崩溃 | P1 | **已修复**：每次都先 `startForeground` 再判断 |

### 2.9 离线

学习、评分、写回全部在本机完成，离线可用；同步失败不影响学习。Web 页面只从 APK 内的 assets 和 collection.media 读取文件，没有网络请求。

### 2.10 外观与无障碍

- **深色模式（P2，已修复）**：原 CSS 依赖 `prefers-color-scheme`，而 WebView 是否上报深色取决于系统与 AnkiDroid 主题是否一致。现在 Activity 把 AnkiDroid 当前主题以 `?theme=dark|light` 传给页面，CSS 用同一套颜色变量覆盖两种情况；反馈色在深色下也有足够对比度。
- **字号（P2，已修复）**：WebView 默认不跟随系统字体大小。现在 `textZoom = fontScale × 100`，CSS 用 rem 并允许换行。
- **横屏/平板（P2，已修复）**：平板上课程两列、宠物放大；横屏矮屏时隐藏答题页的宠物图，反馈面板最高 70% 屏高并可滚动。
- **读屏（P2，已修复）**：新题出现时焦点移到题干；选择题使用 `radio`/`checkbox` 语义和 `aria-checked`；进度条有 `aria-valuenow`；反馈面板 `role="alert"`；所有图标按钮有 `aria-label`；`prefers-reduced-motion` 关闭动画。
- **触控（P3）**：所有按钮最小 48px。
- **体积（P3，已修复）**：`seal-atlas.png` 2.4 MB → `seal-atlas.webp` 0.22 MB（1152×768，保留透明）。

### 2.11 文案与国际化

原来所有界面文案硬编码中文（JS 与 Kotlin）。现在：

- Kotlin：`res/values/seal_learning.xml`（英文默认）和 `res/values-zh/seal_learning.xml`（中文），单独文件，rebase 上游时不冲突。
- Web：`assets/learning/i18n.mjs` 集中中英文两张表，按系统语言选择；单元测试保证两张表的键完全一致。

## 3. 改动位置

尽量收在 `learning/` 包与 `assets/learning/` 内：

- 新增：`SyncEndpointSwap.kt`、`i18n.mjs`、`seal-atlas.webp`、`values-zh/seal_learning.xml`、JS 与 Kotlin 测试。
- 上游文件仅有的改动：`AndroidManifest.xml`（`LearningActivity` 的 `configChanges` 与 `windowSoftInputMode`）、`ActivityList.kt` 测试清单（`ActivityStartupMetaTest` 要求每个 Manifest Activity 都在清单里，原提交缺了这一步）。

## 5. 后续建议

1. 在有 Android SDK 的机器上运行 `./gradlew :AnkiDroid:testPlayDebugUnitTest --tests 'com.ichi2.anki.learning.*'` 与 `ActivityStartupMetaTest`、`AllActivitiesRecreationTest`，再 `assemblePlayDebug` 真机走一遍 SSH 连接与断开。
2. 入口：在 DeckPicker 为「小海豹通用学习」牌组加一个显眼按钮或添加应用快捷方式（长按图标直达），需要动上游布局，单独评估。
3. 卡片模板：让「小海豹通用学习」的 Anki 模板在普通复习里显示可读内容，避免孩子在普通复习里看到 JSON。
4. SSH：考虑在连接成功后自动触发一次同步；若有多个家庭成员，可以在设置页列出已记住的隧道登录并允许清除。
5. 学习数据：总结页可加入「本周学习天数」等轻量激励；需要先确认不会和 FSRS 的间隔目标冲突。
